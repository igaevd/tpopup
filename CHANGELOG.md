# tpopup change log

## v2.0 2026-10-23
- Models tab:
  - Predefined model providers (OpenAI, Anthropic, Gemini, and others)
  - JSON headers, Test/Save, Browse (with live model search)
  - Service tier picker per provider (e.g., OpenAI Ultrafast)
- Translation window changes:
  - editable source
  - retranslate (⌘↩)
  - swap back (⇧⌘↩)
- Grammar/Style progress: top-of-screen island instead of the centred pill
